# Тренажёр «Приближённые значения и округление» — версия 2

Изменения:
- расширена теория по округлению целых чисел до десятков и сотен;
- добавлена свободная навигация между всеми учебными блоками;
- добавлен отдельный блок «Домашнее задание»;
- добавлен отдельный блок «Дополнительная практика»;
- варианты ответов распределены по разным позициям, правильный ответ не стоит систематически первым;
- каждый блок можно пройти повторно независимо от остальных.

## GitHub Pages
Замените в репозитории три файла: `index.html`, `style.css`, `script.js`.
Если репозиторий новый: Settings → Pages → Deploy from a branch → main → / (root).
